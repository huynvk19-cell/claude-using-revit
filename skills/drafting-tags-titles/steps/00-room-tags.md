# 00 · Room tags (tag phòng)

**Skill** `drafting-tags-titles` · **Standard** `drafting-annotation.md` room tags · **Tools** `room_tags_outside`, `room_tags_broken`
**Applies to** every view of the job (room tags), or the sheets of the job (titles).

## Do

- **Outside its room** (no leader into the room) → `room_tags_outside` preview → apply: moves the tag to the room point, leader off. A tag outside with a leader ending in its room is placed on purpose (RT4) and is not listed.
- **Missing** (a room with no tag) → the "Tag room" card of `drafting-plan-dims` (floor plans) or `drafting-ceiling-plan` (ceiling plans).
- **Shows "?"** → `room_tags_broken` apply: colours the tag red; report the room as a model-side fix. Never edit the room.

## Done when

- `room_tags_outside` = 0; every "?" tag red and listed as model-side.

## Skip only if

The view shows no rooms.

## Never

- Edit a room (R1).

## Score (0–10)

No deductions of its own yet: 10 when every **Done when** line holds; otherwise lower it and say which line failed. Ask the user for the deductions of this card when they review it, then write them here.
