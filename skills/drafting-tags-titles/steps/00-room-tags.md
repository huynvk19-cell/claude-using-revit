# 00 · Room tags (tag phòng)

**Skill** `drafting-tags-titles` · **Standard** `drafting-annotation.md` room tags · **Tools** `room_tags_outside`, `room_tags_broken`
**Applies to** every view of the job (room tags), or the sheets of the job (titles).

## Do

- **Outside its room** → `room_tags_outside` preview → apply: moves the tag to the room point, leader off.
- **Shows "?"** → `room_tags_broken` apply: colours the tag red; report the room as a model-side fix. Never edit the room.

## Done when

- `room_tags_outside` = 0; every "?" tag red and listed as model-side.

## Skip only if

The view shows no rooms.

## Never

- Edit a room (R1).
