# 01 · Viewport type (type viewport)

**Skill** `drafting-views-sheets` · **Standard** `drafting-views-sheets.md` § viewport · **Tools** `set_viewport_type`
**Applies to** every view of the job (crop, grid ends, template), or the sheets of the job (viewport type, titles, drawing list).

## Do

`set_viewport_type` preview → apply with `logPath` (undo from the log).

## Done when

- Every viewport of the job in the type the standard / profile names.

## Skip only if

The viewport types are already right (step 00 / preview shows nothing to change).
