# 02 · Crop (crop view)

**Skill** `drafting-views-sheets` · **Standard** `drafting-views-sheets.md` § crop · **Tools** `view_crop_info`, `crop_side_to_grids`
**Applies to** every view of the job (crop, grid ends, template), or the sheets of the job (viewport type, titles, drawing list).

## Do

- `crop_side_to_grids` preview → apply with `logPath`: each side at the distance the standard gives beyond the outer grids / the drawing.
- A Scope Box attached to the view locks the crop: report it as manual, do not detach it.

## Done when

- Every crop set per the standard, or listed as manual (Scope Box) under Việc tồn.

## Skip only if

The user says the crops are final.

## Never

- Shrink an annotation crop, or turn on one the user did not ask for.
