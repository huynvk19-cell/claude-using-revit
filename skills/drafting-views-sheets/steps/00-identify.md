# 00 · Identify the views (xác định view)

**Skill** `drafting-views-sheets` · **Standard** `drafting-views-sheets.md` §1 · **Tools** `sheet_browser_names`, `sheet_views_ids`, `view_crop_info`
**Applies to** every view of the job (crop, grid ends, template), or the sheets of the job (viewport type, titles, drawing list).

## Do

- Resolve the views and sheets with `sheet_browser_names` / `sheet_views_ids`; report names as the Project Browser shows them.
- `view_crop_info` per view: crop on / off, annotation crop, Scope Box, View Template, dependent / parent.

## Done when

- Every view of the job has: exact name, sheet, ViewType, crop state, Scope Box (yes / no), View Template.

## Skip only if

Never.
