# 09 · XB2 Handrail tags (tag tay vịn)

**Skill** `drafting-stair-section-cross` · **Standard** `drafting-stair-section-cross.md` XB2 · **Tools** `annot_place`, `tag_leaders_info`
**Applies to** every section across the flights of the job, one view per call (`timeoutSeconds`).
**Read first** (once per job): `_tags-common.md`

## Do

- `P01` on each handrail clearly seen in each band (wall handrails, both faces of the centre wall), `P02` on the balustrade of the top floor.
- Head inside the core next to the rail, short **horizontal** leader, dot on the rail.

## Done when

- One tag per clearly seen handrail per band, leaders horizontal.

## Skip only if

A handrail hidden by a bigger railing: no tag.
